# M02 — Os 4 conceitos do M01 com o nome "CronôBR"

```
Create ONE brand exploration sheet, 1536x1024 landscape, plain #121212 background, for "CronôBR", an interval
workout timer app. Show FOUR numbered logo concepts side by side, each with an app icon (rounded square 1:1) on top
and below it the horizontal lockup icon + wordmark.
WORDMARK (critical): spelled exactly C-r-o-n-ô-B-R, "CronôBR", the second "o" carries a clearly visible circumflex
accent (ô, a small chevron hat). "Cronô" white, "BR" orange #FF6B35, bold geometric sans. Draw the circumflex as part
of the lettering, same weight family, clearly separated above the o.
Palette only: orange #FF6B35, white, near-black #121212, gray #2A2A2A / #B0B0B0. Flat vector, no 3D, no gradients.
1. "Anel": thick orange ring with a gap at the top right like a progress arc, short crown on top; icon on near-black.
2. "C de tempo": bold letter C made of a progress arc with a small play triangle inside; orange icon background, white mark.
3. "Intervalos": stopwatch circle split into alternating orange and gray segments, minimal crown; icon on near-black.
4. "Pulso": ring whose bottom becomes a small heartbeat zigzag line, crown on top; icon on near-black.
Under each concept a tiny gray caption: "1. Anel", "2. C de tempo", "3. Intervalos", "4. Pulso". No other text.
```
